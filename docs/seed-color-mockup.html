种子色派生方案对比：3 种子色够不够？

问题：只给 primary + secondary + bg 三个种子色，粗体/斜体色能自动派生吗？

三列对比：
A 当前 手工精选的粗体/斜体颜色（我们上一轮的成果）
B 加深30% 仅用 color-mix(seed, black 30%) 自动加深 → primary→bold, secondary→italic
C 加深40% 加深力度更大 → color-mix(seed, black 40%)

核心矛盾：Forest/Mint/Mauve/Golden/Cheery/Prussian 的正文色自带主题色调，加深 primary 得到的粗体色与正文同色系，可能无法突出
☀️ 浅色模式 — 手选 vs 自动派生
🌙 暗色模式 — 直接用 primary/secondary（天然够用）
